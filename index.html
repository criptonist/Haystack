Пока пусто. Стог ждёт первую иголку.
Каждый клик генерирует случайный приватный ключ secp256k1 в браузере и выводит связанные адреса: P2PKH сжатый, P2PKH несжатый, P2SH-P2WPKH и Bech32.

Можно также вручную ввести собственный приватный ключ в HEX и нажать «Проверить ключ».

Проверка состояния адресов выполняется через публичный API Blockstream. Жёлтая точка означает, что у адреса есть история транзакций. Красная точка означает, что транзакций не обнаружено.
