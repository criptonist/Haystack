Проверка баланса выполняется через публичный API blockstream.info. Если API недоступен, будет показано «н/д». Для проверки используется только введённый или сгенерированный ключ.

Каждый клик генерирует случайный приватный ключ secp256k1 в браузере и выводит связанные адреса: P2PKH сжатый, P2PKH несжатый, P2SH-P2WPKH и Bech32. Для ручной проверки можно ввести любое HEX-число длиной от 1 до 64 символов. Перед вычислением оно дополняется нулями слева до 32 байт.
